·Connect to the backend

Requires DEV_SKIP_AUTH=true in the backend's .env (see app/deps.py) — no token needed. CORS note: the backend's CORSMiddleware only allows FRONTEND_ORIGIN (default http://localhost:3000) — opening this file directly (file://) will be blocked unless you serve it from an allowed origin (e.g. python -m http.server) or add this origin to FRONTEND_ORIGIN.

2Pick from what got ingested

Picking fills in Topic, Subtopic, Grade, Subject, and Content below — all still plain fields, so edit freely before copying the CLI command. Ingested books are saved in this browser (localStorage) and survive a refresh.
